    How to read this page

    Status code

    The 3-digit answer a website sends back. 2xx means OK and 3xx is a redirect, so both count as up. 4xx (refused or not found) and 5xx (server broken) count as down. No code at all means the site didn't answer.

    Response time

    How long the site took to answer, in milliseconds (1000 ms = 1 s). Under 500 ms is fast and over 3 s feels slow. Rising response times are often the first sign of trouble.

    SSL expiry

    Days until the site's HTTPS certificate (the 🔒) expires. If it isn't renewed in time, browsers show "Your connection is not private". You get a warning 14 days ahead.

    Uptime %

    The share of checks that succeeded. 99.9% over a month means about 43 minutes of downtime. The coloured bars show the last 30 checks, newest on the right.
